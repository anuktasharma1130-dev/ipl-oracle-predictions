3. EXPECTED INPUT SCHEMA
  POST /api/predict accepts application/json:
  {
      "team1": str (required, e.g. "Mumbai Indians" or "MI"),
      "team2": str (required, e.g. "Chennai Super Kings" or "CSK"),
      "venue": str (required, e.g. "Wankhede Stadium"),
      "city": str (optional, auto-derived from venue if omitted),
      "toss_winner": str (optional, required if toss_decision is passed; must be team1 or team2),
      "toss_decision": str (optional, required if toss_winner is passed; "bat" or "field")
  }

4. VALIDATION ERRORS TESTED & VERIFIED
  - Identical Teams:
      Input: team1="Mumbai Indians", team2="Mumbai Indians"
      Result: HTTP 400 Bad Request ("team1 and team2 must be different teams.")
  - Team Code Alias Identical:
      Input: team1="MI", team2="Mumbai Indians"
      Result: HTTP 400 Bad Request ("team1 and team2 must be different teams.")
  - Unknown Team:
      Input: team1="Mars Invaders", team2="Chennai Super Kings"
      Result: HTTP 400 Bad Request ("Unknown team 'Mars Invaders'. Must be one of the known IPL franchises...")
  - Invalid Toss Winner:
      Input: team1="Mumbai Indians", team2="CSK", toss_winner="Kolkata Knight Riders"
      Result: HTTP 400 Bad Request ("toss_winner 'Kolkata Knight Riders' must be either team1 or team2.")
  - Invalid Toss Decision:
      Input: toss_decision="sleep"
      Result: HTTP 400 Bad Request ("toss_decision 'sleep' must be either 'bat' or 'field'.")
  - Partial Toss Information:
      Input: toss_winner="Mumbai Indians", toss_decision omitted
      Result: HTTP 400 Bad Request ("toss_decision must be specified when toss_winner is provided.")

8. KNOWN LIMITATIONS
  - Historical state accumulator reflects match outcomes up through the final match of the historical
    dataset (1,234 matches). Matches beyond the historical dataset require feeding updated base matches.
  - Single-tree-split estimators without explicit ball-by-ball player availability rely on macro team-level
    and venue-level dynamics; player injuries, player auction transfers, or squad changes are not modeled.
