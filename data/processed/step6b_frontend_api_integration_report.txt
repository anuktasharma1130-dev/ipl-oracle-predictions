1. EXACT JAVASCRIPT FUNCTIONS MODIFIED
  File modified: ipl.html
  - function generatePrediction():
      Converted into an async function that gathers user-selected parameters (#team1, #team2,
      #match-venue, #toss-winner, #toss-decision), displays a loading spinner state ("Analyzing match..."),
      temporarily disables the Predict button, dispatches an HTTP POST request to the Flask ML API,
      validates the response, handles errors, and triggers displayPrediction() and createConfetti().
  - function calculatePrediction(team1Code, team2Code):
      COMPLETELY REMOVED. The heuristic win percentage / recent form / static h2h arithmetic
      that generated fake probabilities was permanently deleted.
  - function generateAnalysis(team1, team2, team1Prob, team2Prob):
      REPLACED with an ML-driven explanation engine that explains predictions using model
      type (Pre-Toss vs Post-Toss HistGradientBoosting), win probability spread, historical Elo ratings,
      Elo delta, toss decision dynamics, and venue chase conversion rates.
  - function displayPrediction(team1, team2, apiResult):
      UPDATED to bind directly to the ML API response fields (team1_win_probability,
      team2_win_probability, predicted_winner, confidence, and details).
  - Helper functions added:
      * updateMatchOptions(): Dynamically sets default home venue for Team 1 and populates team names in toss selector.
      * showPredictionError(message): Displays clean error container (#prediction-error) and suppresses prediction results.
      * clearPredictionError(): Clears error banners prior to new prediction requests.

2. OLD PREDICTION LOGIC REMOVED / BYPASSED
  - Removed heuristic win percentage arithmetic: `let team1Prob = team1.winPercentage; team1Prob += (team1Form - 0.5) * 10;`
  - Removed static head-to-head arithmetic adjustments: `team1Prob += (h2hWinRate - 0.5) * 5;`
  - Removed arbitrary heuristic winner determination: `if (Math.abs(team1Prob - team2Prob) < 5) ...`
  - Bypassed all hard-coded probability calculation in favor of the Flask ML API as the single source of truth.
  - Retained historical team metadata (`teamData`) for team icons, theme colors, home venues, and player rosters across the rest of the application.

3. API ENDPOINT USED
  Endpoint: POST http://127.0.0.1:5000/api/predict
  Content-Type: application/json
  CORS: Enabled across all origins on backend.

4. REQUEST PAYLOAD
  Pre-Toss Request Payload:
  {
      "team1": "Mumbai Indians",
      "team2": "Chennai Super Kings",
      "venue": "Wankhede Stadium"
  }

  Post-Toss Request Payload:
  {
      "team1": "Gujarat Titans",
      "team2": "Rajasthan Royals",
      "venue": "Narendra Modi Stadium",
      "toss_winner": "Gujarat Titans",
      "toss_decision": "field"
  }

5. RESPONSE FIELDS USED
  The frontend consumes the following fields directly from the API JSON response:
  - data.status ("success" / "error")
  - data.model ("pre_toss" / "post_toss" -> displayed in #ml-model-badge and #ml-model-mode)
  - data.team1_win_probability (formatted to 2 decimal places with % in #team1-prob)
  - data.team2_win_probability (formatted to 2 decimal places with % in #team2-prob)
  - data.predicted_winner (displayed in #predicted-winner)
  - data.confidence (displayed in #confidence-level)
  - data.details.team1_home_advantage (displayed in #venue-advantage)
  - data.details.h2h_matches_before & h2h_team1_win_rate (displayed in #head-to-head)
  - data.details.elo_diff, venue_chase_win_rate, toss_winner, toss_decision (displayed in #match-analysis)

6. WHETHER PROBABILITIES COME DIRECTLY FROM API
  YES, 100% DIRECT.
  - Zero probability recalculation is performed in JavaScript.
  - Probability display formula:
      `document.getElementById('team1-prob').textContent = `${(apiResult.team1_win_probability * 100).toFixed(2)}%`;`
      `document.getElementById('team2-prob').textContent = `${(apiResult.team2_win_probability * 100).toFixed(2)}%`;`
  - Probability sum strictly equals 100.00%.
