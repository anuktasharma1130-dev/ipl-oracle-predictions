# IPL Oracle REST API Reference

The IPL Oracle API is a lightweight, local REST service built with Flask and Flask-CORS that serves probabilistic match winner predictions generated by trained scikit-learn machine learning pipelines.

---

## Base URL
```
http://127.0.0.1:5000
```

---

## Endpoints

### 1. Health Check
`GET /api/health`

Confirms API availability and operational state.

#### Response (`HTTP 200 OK`)
```json
{
  "service": "IPL Oracle ML API",
  "status": "ok"
}
```

---

### 2. Model Metadata
`GET /api/model-info`

Provides information regarding loaded model pipelines, expected input schemas, feature definitions, and training split partitions.

#### Response (`HTTP 200 OK`)
```json
{
  "available_models": {
    "pre_toss": {
      "name": "pre_toss_improved_histgb",
      "model_type": "HistGradientBoostingClassifier (scikit-learn Pipeline with ColumnTransformer)",
      "expected_feature_count": 36,
      "input_requirements": ["team1", "team2", "venue"],
      "optional_inputs": ["city"]
    },
    "post_toss": {
      "name": "post_toss_improved_histgb",
      "model_type": "HistGradientBoostingClassifier (scikit-learn Pipeline with ColumnTransformer)",
      "expected_feature_count": 40,
      "input_requirements": ["team1", "team2", "venue", "toss_winner", "toss_decision"],
      "optional_inputs": ["city"]
    }

    "training_split": "2008-2023 seasons (1,019 matches)",

  "service": "IPL Oracle ML API",
  "status": "ok"
}
```

### 3. Match Prediction
`POST /api/predict`

Generates probabilistic match winner forecasts for a given fixture.

#### Request Headers
```
Content-Type: application/json
```

#### Pre-Toss Request Payload
When toss information is omitted, the API automatically executes the **Pre-Toss** model.
```json
{
  "team1": "Mumbai Indians",
  "team2": "Chennai Super Kings",
  "venue": "Wankhede Stadium",
  "city": "Mumbai"
}
```

#### Post-Toss Request Payload
When both `toss_winner` and `toss_decision` are supplied, the API routes the request to the **Post-Toss** model.
```json
{
  "team1": "Gujarat Titans",
  "team2": "Rajasthan Royals",
  "venue": "Narendra Modi Stadium",
  "toss_winner": "Gujarat Titans",
  "toss_decision": "field"
}
```

#### Supported Franchise Names & Codes
The API accepts either canonical franchise names or official short codes:
- `Mumbai Indians` (`MI`)
- `Chennai Super Kings` (`CSK`)
- `Royal Challengers Bangalore` (`RCB`)
- `Kolkata Knight Riders` (`KKR`)
- `Sunrisers Hyderabad` (`SRH`)
- `Delhi Capitals` (`DC`)
- `Punjab Kings` (`PBKS`)
- `Rajasthan Royals` (`RR`)
- `Gujarat Titans` (`GT`)
- `Lucknow Super Giants` (`LSG`)
- Historical: `Deccan Chargers`, `Pune Warriors`, `Gujarat Lions`, `Rising Pune Supergiant`, `Kochi Tuskers Kerala`

## Error Responses

The API returns standard HTTP status codes with structured JSON error bodies:

### 1. Same Team Selection (`HTTP 400 Bad Request`)
```json
{
  "status": "error",
  "error": "team1 and team2 must be different teams. Both specified as 'Mumbai Indians'."
}
```

### 2. Unknown Team Name (`HTTP 400 Bad Request`)
```json
{
  "status": "error",
  "error": "Unknown team 'Atlantis Warriors'. Must be one of the known IPL franchises: ['Chennai Super Kings', 'Deccan Chargers', ...]"
}
```

### 3. Invalid Toss Decision (`HTTP 400 Bad Request`)
```json
{
  "status": "error",
  "error": "toss_decision 'sleep' must be either 'bat' or 'field'."
}
```

### 4. Missing Required Parameter (`HTTP 400 Bad Request`)
```json
{
  "status": "error",
  "error": "Parameter 'venue' is required and must be a non-empty string."
}
```

## Local Setup & Execution

### 1. Install Dependencies
```bash
pip install -r requirements-api.txt
```

### 2. Launch Server
```bash
python api/app.py
```
By default, the server binds to `127.0.0.1:5000`.

### 3. Verify Health
```bash
curl http://127.0.0.1:5000/api/health
```
